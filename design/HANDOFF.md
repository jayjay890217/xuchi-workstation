# 旭馳工作台改版：交給 Claude Code 的說明

把這份檔案和 `demo.html` 一起放進 `xuchi-workstation` repo（建議放在 `design/` 資料夾），然後對 Claude Code 說：

> 讀 `design/HANDOFF.md` 和 `design/demo.html`，照裡面的規範把旭馳工作台改版。先做第一階段，做完截圖給我看。

## 0. 目標

`demo.html` 是已經確認過外觀的示範頁（假資料）。要做的是：
1. **外觀和操作完全照 demo.html**，不要自己重新設計。
2. 把 demo 裡的假資料換成旭馳APP資料庫的真資料。
3. 這一頁是店裡共用電腦開機的固定首頁，老闆、櫃台、技師都會用。

## 1. 絕對要遵守的規則

- **所有顏色、字級、圓角、間距只能用 `:root` 裡的 CSS 變數**，不可以在元件裡寫死色碼。新增需要的值就先加到變數裡。
- **橘色（`--brand`）只用在：Logo、主要按鈕、目前所在選單的橘色細線、縮起選單時的提醒點。** 任何「狀態」都不可以用橘色或黃色。
- **狀態只有四種顏色**，用 `.pill` 膠囊標籤：
  | class | 顏色 | 用在 |
  |---|---|---|
  | `.ok` | 綠 | 已完工、已送出、正常 |
  | `.run` | 藍 | 施工中、進行中 |
  | `.wait` | 紫 | 待料、待確認、等回覆 |
  | `.bad` | 深玫瑰紅 | 需聯絡、異常、逾期 |
- 標籤、數字、金額、車牌**不可以換行**（`white-space:nowrap`）。
- 圖示用 demo 裡的 inline SVG `<symbol>`，或 Lucide，**不要用 emoji**。
- 字型：內文 Noto Sans TC，數字用 Inter（class `num`）。
- 側欄固定深色，不跟著亮／暗主題變；主畫面要支援亮色和暗色。
- 寬度 860px 以下：側欄變成從左滑出的抽屜；600px 以下：表格改成一列一張卡（`.stack`）。
- 從資料庫讀到的文字一律用 `textContent` 或先跳脫（demo 裡的 `esc()`），不可以直接塞進 innerHTML。
- 每做完一個階段，**開瀏覽器截圖**，寬版（1440px）和手機（390px）各一張，給使用者看過再往下做。

## 2. 畫面結構（照 demo.html）

**側欄**（`.side`，可收合）
- 上方：Logo「旭」＋「旭馳 / 工作台」。
- 資訊卡：旭馳車業＋今天工單數。
- 選單分兩組：
  - 每天：今日總覽、KEY 單、報價、店務筆記、廠商公告（後四個有數字徽章）
  - 管理：輪胎批發、月報
- 底部：「櫃台電腦・大家共用」。
- ☰ 按鈕：寬螢幕縮成圖示列（記在 localStorage `xc-mini`），窄螢幕開關抽屜（點遮罩、⊗、Esc 關閉）。

**今日總覽**（首頁）
1. 標題列：☰、標題＋日期、搜尋框、橘色「新增 KEY 單」按鈕。
2. 四張數字卡：今日工單、待處理報價、機油預付剩餘、等你確認。
3. 左：今日工單表格（全部／施工中／待料／已完工 篩選，可搜尋）。右：店務筆記（打勾確認；預支、調撥顯示「需確認才送出」）。
4. 左：工具捷徑（AppSheet 業績、頭家好幫手、綠界、打卡之星、報價單、官方網站，全部開新視窗）。右：廠商公告待審（按「發佈」）。

## 3. 資料怎麼接

- 資料來源：**旭馳APP資料庫**（AppSheet 旭馳雲端系統用的同一份 Google 試算表：工單、維修明細、零件、客戶）。
- 做法：用 Google Apps Script 開一個 Web App 當 API（`doGet` 回傳 JSON），工作台用 `fetch` 讀取。
- **Apps Script 一定要建在 xcgssystem@gmail.com 帳號底下。**
- 不可以改 AppSheet 的資料表結構；`零件` 表不要動（不扣庫存）。
- 需要的讀取接口：
  | 接口 | 給哪一區 |
  |---|---|
  | `?action=today` | 今日工單列表＋數字卡 |
  | `?action=quotes` | 待處理報價數、最久等幾天 |
  | `?action=oil` | 機油預付剩餘次數（依資料庫計算，不手算） |
  | `?action=notes` | 店務筆記 |
  | `?action=news` | 廠商公告草稿 |
- 店務筆記規則：分類為員工預支、員工自用、調撥（規速車業雙向）、缺貨、幫客人叫貨；定期用 LINE 傳給櫃台老闆娘；**預支和調撥要按確認後才送到專用群組**。
- 廠商公告：每天早上整理成草稿，使用者在這裡按「發佈」才會上官網。
- 網路斷線時要顯示「離線中，請改用 AppSheet」，不要整頁空白。

## 4. 分階段

1. **第一階段**：照 demo 做出版面（側欄、今日總覽、工具捷徑的真實連結），資料先用 demo 的假資料。設成開機首頁。
2. **第二階段**：寫 Apps Script API，接今日工單、報價、機油預付。
3. **第三階段**：店務筆記（新增、確認、LINE 通知）。
4. **第四階段**：廠商公告審核與發佈、KEY 單／報價／輪胎批發／月報各自的頁面（沿用同一套元件）。

## 5. 新頁面怎麼做

其他頁面（KEY 單、報價、輪胎批發、月報）**一律重用 demo 裡現有的元件**：`.card`、`.ch`（卡片標題列）、`.kpi`、`table.stack`、`.pill`、`.seg`（分段篩選）、`.btn` / `.btn.pri` / `.btn.sm`、`.tag`。不要另外發明新樣式。真的需要新元件時，先做一個給使用者確認。
